   SSH 有安全机制：**私钥不能让其他人有读取权限**，`600` 就是只有文件所有者（你 root）能读写，别的用户完全碰不到，SSH 才允许用它登录。  

+ `6` = 二进制 `110` → 读 (4) + 写 (2)，**没有执行权限**
+ `0` = 二进制 `000` → 不能读、不能写、不能执行

`600` 拆开：

+ 第一位 6：**文件所有者（root）**：可读、可写
+ 第二位 0：同组别的用户：啥权限都没有
+ 第三位 0：系统里其他所有用户：啥权限都没有

对应权限字符串：`-rw-------`

**一、题目分析** 

**  **拿到流量包 **pcap 文件**，常规思路是先直接搜索关键词 flag，看是否直接存在明文 flag；如果搜索不到，再尝试追踪 TCP 流，还原完整通信内容，很多时候 flag 藏在 TCP 会话的传输数据里，单独数据包检索匹配不到。

**二、解题步骤**

1、尝试直接搜索flag

  用 Wireshark 打开 `easycap.pcap`

  打开查找分组（快捷键 `**Ctrl+F**`）

  查找类型选择：字符串，搜索内容输入：`flag`

  搜索结果：没有匹配到包含 flag 的数据包，说明 flag 不在单独数据包的简单字符串检索位置，需要还原整条 TCP 会话

2、 追踪 TCP 流（tcp.stream eq 0）  

  在数据包列表，选中第一个 TCP 会话数据包，追踪TCP流。过滤器自动变成 `tcp.stream eq 0`，代表第 0 号 TCP 流。在弹出的TCP流窗口中直接出flag。

**三、总结**

TCP 是面向连接、分片传输的。一条消息太长，会被切成好几个小包分开发；Ctrl+F 只是在单个数据包里面搜，自然搜不到完整 flag；追踪 TCP 流就是把这一整条连接里所有分片按顺序拼回原始数据。
